# ADR-001: Docker for package management

## Status

Accepted.

## Context

Contributors run different Node.js versions locally. Dependency installs and lockfile
updates need to happen against a consistent Node version so `yarn.lock` doesn't churn
between machines.

## Decision

All package management goes through the `frontend` Docker Compose service, which pins
`node:22-alpine`:

```
docker-compose run --rm frontend yarn add <package>
docker-compose run --rm frontend yarn add -D <package>
docker-compose run --rm frontend yarn remove <package>
```

`make dev`, `make lint` and `make test` already run inside the same container.

## Consequences

- No local Node install is required to contribute.
- `yarn.lock` is only ever regenerated by the pinned container version.
